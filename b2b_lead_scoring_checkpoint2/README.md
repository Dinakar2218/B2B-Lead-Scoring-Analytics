# B2B Marketplace Lead Scoring — Checkpoint 2

This repository contains a repeatable Python/SQL data pipeline and baseline analysis for a B2B lead-scoring project.

## What is included

- `src/generate_sample_data.py` — creates a reproducible, clearly labelled synthetic 12-month lead dataset when the portal data is unavailable.
- `src/pipeline.py` — validates, cleans and transforms lead data; writes baseline metrics and a SQLite analytical table.
- `sql/baseline_metrics.sql` — repeatable SQL queries for business metrics.
- `notebooks/01_baseline_analysis.ipynb` — Jupyter notebook with business narrative and charts.
- `data/processed/baseline_metrics.csv` — generated summary metrics.
- `data/processed/leads_clean.csv` — cleaned analytical dataset.
- `data/lead_scoring.db` — SQLite database generated by the pipeline.

## Data fields

The expected input schema is: `lead_id`, `created_date`, `industry`, `company_size`, `enquiry_type`, `response_time_hours`, `number_of_rfqs`, and `converted`.

The three links supplied in the project portal currently return the Candidate Portal HTML page rather than downloadable CSV content. Therefore, the repository includes a reproducible synthetic sample for pipeline demonstration only. Replace `data/raw/leads.csv` with the authorised lead-level dataset using the same schema before reporting production conclusions.

## Run locally or in Google Colab

```bash
pip install -r requirements.txt
python src/generate_sample_data.py
python src/pipeline.py
jupyter notebook notebooks/01_baseline_analysis.ipynb
```

## Data-quality controls

The pipeline checks required columns, duplicate lead IDs, invalid dates, negative response times/RFQs, and non-binary conversion values. It fails with a clear message if the schema is unsuitable.
